# Security policy

## Reporting a vulnerability

Report security vulnerabilities by email to **development@otapp.net**.

Include enough detail for us to reproduce or assess the issue (affected component, version or commit if known, and steps or proof of concept when safe to share). We will acknowledge receipt and coordinate on disclosure timelines where appropriate.

## Scope

This file is the default organization security policy for Otapp Agency repositories that do not define their own `SECURITY.md`.
